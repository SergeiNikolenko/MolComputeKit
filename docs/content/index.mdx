# MolComputeKit

MolComputeKit is a native Rust SDK for **molecular numerical workloads**. It
pairs portable reference implementations with a hash-verified Apple Metal
runtime and a versioned protocol for jobs, capabilities, artifacts, and helper
processes.

It is intentionally not a cheminformatics application. You provide typed,
chemistry-aware inputs such as packed fingerprints, atom coordinates, distance
constraints, or MMFF parameters. MolComputeKit validates and computes over
those inputs. Your host remains responsible for parsing SMILES/SDF files,
chemical perception, persistence, UI, and result presentation.

## What runs where

| Surface | Purpose | Availability |
| --- | --- | --- |
| `molcompute_kit::core` | deterministic CPU/reference algorithms | Linux and macOS |
| `molcompute_kit::protocol` | bounded requests, plans, evidence, and artifacts | Linux and macOS |
| `molcompute_kit::metal` | verified native Metal execution | macOS 14+ on Apple Silicon |
| `molcompute-service` | authenticated, out-of-process Metal execution | macOS 14+ on Apple Silicon |

The repository does not include a prebuilt Metal library or signed helper.
Applications that use the GPU path must build, package, hash, and ship those
artifacts themselves.
